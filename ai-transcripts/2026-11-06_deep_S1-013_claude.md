  Assumptions

  - No placeholder auth function was needed. S1-009/010 are merged, so the
    routes use the real requireApiUser(), and tests mock getAuthenticatedUser.
  - Ingestion is a minimal stub. It always returns 409 in practice until there's
    a server-side way to set google_place_id, which S1-014 left undecided. It
    only starts the provider job; it doesn't fetch, normalize or save reviews.
    S1-019 can replace it and keep using getOwnedTargetOrThrow.
  - Each review route checks ownership twice: the route calls the helper, and
    the existing review service checks again on its own. That's one extra small
    query per request, which I left in as a second safeguard.
  - 404, not 403, for foreign targets, matching the existing TARGET_NOT_FOUND
    convention.
  - POST reviews is limited to 100 reviews, and if any one review is invalid the
    whole batch is rejected.
