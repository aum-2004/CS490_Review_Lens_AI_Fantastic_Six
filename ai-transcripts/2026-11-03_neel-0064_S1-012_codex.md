## 2. Exact S1-012 requirements

An authenticated user must not read or modify an AnalysisTarget belonging to another
authenticated user, even when the attacker knows the correct target identifier.

Applicable rules:
- S1-BR-007: User-scoped records have authenticated owners.
- S1-BR-008: Cross-user reads and writes are denied.
- S1-BR-009: Authorization must be enforced on the backend or persistence layer.
- S1-BR-010: Client-supplied owner IDs cannot establish ownership.
- S1-BR-016: Users may view or open only their own targets.

Required test scenario:

1. User A owns Target A.
2. User A can retrieve Target A.
3. User B deliberately requests Target A using its known ID.
4. User B cannot retrieve Target A.
5. User B attempts an update or delete against Target A.
6. The unauthorized modification is denied.
7. User A can subsequently retrieve Target A and verify that its data remains unchanged.
8. Unauthenticated requests are rejected where applicable.

The tests must prove protection at the database or backend boundary, not merely that the UI hides
the target.
