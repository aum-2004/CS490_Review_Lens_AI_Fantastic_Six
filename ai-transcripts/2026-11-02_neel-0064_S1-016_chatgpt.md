5. Missing source URL.

- Validation performs no HTTP requests, scraping, redirect following, DNS lookup, or provider calls.

## 4. Conflicting or missing requirements

These require a team decision:

1. **Provider conflict:** S1-001 says the review provider is pending; S1-002 fixes the UI to Google Maps.

2. **Hostname rules are unspecified:** S1-002 says accepted Google Maps hostnames belong in the schema but does not list them. The team must decide among formats such as:
   - `www.google.com/maps/...`
   - `maps.google.com/...`
   - `maps.app.goo.gl/...`
   - Legacy `goo.gl/maps/...`
   - Country-specific Google domains

3. **Path requirements:** An exact Google hostname alone may not prove the URL is a Maps URL. Accepted path rules must be confirmed.

4. **Short links:** They can be recognized syntactically, but their final destination cannot be verified without following redirects—which is explicitly out of scope.

5. **Field contract:** No implementation currently establishes whether the input property is `name`, `targetName`, or `entityName`.

6. **Platform input:** S1-015 allows the platform to be fixed. I recommend that the server assign the single supported platform rather than trust a browser-supplied platform value.

7. **HTTP wording:** Validation permits both HTTP and HTTPS, while the malformed-URL message tells users to begin with `https://`. The proposed behavior is to accept both protocols while retaining the approved message.

8. **URL length:** No maximum is specified. I would not invent one without team approval.

9. **Character counting:** I recommend counting user-visible Unicode code points for the 120-character name limit, consistent with PostgreSQL character-length behavior.

10. **Unknown properties:** I recommend returning only allowlisted validated fields and never propagating `ownerId` or `userId`. Whether all other unknown properties should be rejected or ignored should be aligned with S1-015.

## 5. Recommended interfaces and result structure

Subject to coordination with S1-014, I recommend:

```ts
export const SUPPORTED_REVIEW_PLATFORM = "google_maps" as const;

export type SupportedReviewPlatform = typeof SUPPORTED_REVIEW_PLATFORM;

export interface ValidatedAnalysisTargetInput {
  name: string;
  sourceUrl: string;
  platform: SupportedReviewPlatform;
}

export type AnalysisTargetInputField = "name" | "sourceUrl";

export type AnalysisTargetValidationErrorCode =
  | "INVALID_INPUT_TYPE"
  | "TARGET_NAME_REQUIRED"
  | "TARGET_NAME_INVALID_TYPE"
  | "TARGET_NAME_TOO_LONG"
  | "SOURCE_URL_REQUIRED"
  | "SOURCE_URL_INVALID_TYPE"
  | "SOURCE_URL_MALFORMED"
  | "SOURCE_URL_UNSUPPORTED_PROTOCOL"
  | "SOURCE_URL_UNSUPPORTED_PLATFORM";

export interface AnalysisTargetValidationIssue {
  field?: AnalysisTargetInputField;
  code: AnalysisTargetValidationErrorCode;
  message: string;
}

export type AnalysisTargetValidationResult =
  | {
      success: true;
      data: ValidatedAnalysisTargetInput;
    }
  | {
      success: false;
      error: {
        code: "INVALID_ANALYSIS_TARGET_INPUT";
        message: string;
        issues: readonly AnalysisTargetValidationIssue[];
      };
    };

export function validateAnalysisTargetInput(
  input: unknown,
): AnalysisTargetValidationResult;
```

Recommended validation behavior:

1. Require a non-null, non-array object.
2. Validate fields in deterministic order: name, then URL.
3. Require strings before applying string operations.
4. Trim values.
5. Apply the name length limit after trimming.
6. Parse with the native `URL` implementation.
7. Check protocol explicitly.
8. Compare the normalized `URL.hostname` against an explicit allowlist.
9. Apply any confirmed hostname/path pairing rules.
10. Return only normalized, allowlisted fields plus the server-controlled platform.

The validator should collect independent name and URL errors in one pass, but return only the most actionable error for each field.

## 8. Security risks and mitigations

- **Hostname spoofing:** Use parsed `hostname` equality against an explicit allowlist, never `includes`, `endsWith` without a dot boundary, or raw-string substring matching.
- **User-info confusion:** Consider rejecting URLs containing usernames or passwords even when the final hostname is approved.
- **Homograph domains:** Rely on normalized parsed hostname and an explicit ASCII allowlist.
- **Ownership forgery:** Never accept or return browser-supplied `ownerId` or `userId` as authenticated ownership.
- **SSRF misconception:** Format validation is not sufficient SSRF protection. Future ingestion code must separately control outbound requests and redirects.
- **External side effects:** The validator will make no network or provider calls.
- **Information leakage:** Return fixed safe messages without stack traces, parser exceptions, credentials, or provider details.
- **Resource abuse:** Enforce the name bound; a URL-size bound should be added only after the team specifies one.
- **Prototype or malformed input:** Validate the top-level shape and field types before accessing string methods.

const TARGET_NAME_REQUIRED_MESSAGE = "Enter a name for this target.";

  "That doesn't look like a valid web address. Paste the full link, starting with https://.";
const SOURCE_URL_UNSUPPORTED_MESSAGE =

const GOOGLE_MAPS_HOSTNAMES = new Set(["google.com", "www.google.com", "maps.google.com"]);
const GOOGLE_MAPS_QUERY_PARAMETERS = ["cid", "place_id", "query_place_id", "q", "query"];

function hasOwnProperty(input: Record<string, unknown>, property: string): boolean {
  return Object.prototype.hasOwnProperty.call(input, property);
}

function isRecord(input: unknown): input is Record<string, unknown> {
  return typeof input === "object" && input !== null && !Array.isArray(input);
}

function characterCount(value: string): number {
  return Array.from(value).length;
}

function hasNonEmptyQueryParameter(url: URL): boolean {
  return GOOGLE_MAPS_QUERY_PARAMETERS.some((parameter) => {
    const value = url.searchParams.get(parameter);
    return value !== null && value.trim().length > 0;
  });
}

function isGoogleMapsBusinessUrl(url: URL): boolean {
  if (!GOOGLE_MAPS_HOSTNAMES.has(url.hostname) || url.username || url.password || url.port) {
    return false;
  }

  const path = url.pathname.toLowerCase();
  const placePathPrefix = "/maps/place/";

  if (path.startsWith(placePathPrefix) && path.slice(placePathPrefix.length).length > 0) {
    return true;
  }

  const acceptsBusinessQuery =
    path === "/maps" ||
    path === "/maps/" ||
    path === "/maps/search" ||
    path === "/maps/search/" ||
    (url.hostname === "maps.google.com" && path === "/");

  return acceptsBusinessQuery && hasNonEmptyQueryParameter(url);
}

  return {
    success: false,
    error: {
      code: "INVALID_ANALYSIS_TARGET_INPUT",
      message: "Please fix the highlighted fields.",
      issues,
    },
  };
}

/**
 * Validates and normalizes data for one Google Maps analysis target.
 *
 * S1-015 integration contract: a protected server boundary must call this function with the
 * parsed request body and return the failure as HTTP 400 before invoking persistence. On success,
 * it may pass only result.data to the creation service and must derive ownership independently
 * from the authenticated session.
 *
 * Shortened URLs such as maps.app.goo.gl are intentionally unsupported until S1-020 confirms that
 * the ingestion provider can use them without redirect resolution.
 */
export function validateAnalysisTargetInput(input: unknown): AnalysisTargetValidationResult {
  if (!isRecord(input)) {
    return failure([
      {
        code: "INVALID_INPUT_TYPE",
        message: "Target information must be an object.",
      },
    ]);
  }

  const issues: AnalysisTargetValidationIssue[] = [];
  const rawName = hasOwnProperty(input, "name") ? input.name : undefined;
  const rawSourceUrl = hasOwnProperty(input, "sourceUrl") ? input.sourceUrl : undefined;

  let normalizedName: string | undefined;
  let normalizedSourceUrl: string | undefined;

  if (rawName === undefined || rawName === null) {
    issues.push({
      field: "name",
      code: "TARGET_NAME_REQUIRED",
      message: TARGET_NAME_REQUIRED_MESSAGE,
    });
  } else if (typeof rawName !== "string") {
    issues.push({
      field: "name",
      code: "TARGET_NAME_INVALID_TYPE",
      message: TARGET_NAME_REQUIRED_MESSAGE,
    });
  } else {
    normalizedName = rawName.trim();

    if (normalizedName.length === 0) {
      issues.push({
        field: "name",
        code: "TARGET_NAME_REQUIRED",
        message: TARGET_NAME_REQUIRED_MESSAGE,
      });
    } else if (characterCount(normalizedName) > MAX_TARGET_NAME_LENGTH) {
      issues.push({
        field: "name",
        code: "TARGET_NAME_TOO_LONG",
        message: TARGET_NAME_TOO_LONG_MESSAGE,
      });
    }
  }

  if (rawSourceUrl === undefined || rawSourceUrl === null) {
    issues.push({
      field: "sourceUrl",
      code: "SOURCE_URL_REQUIRED",
      message: SOURCE_URL_REQUIRED_MESSAGE,
    });
  } else if (typeof rawSourceUrl !== "string") {
    issues.push({
      field: "sourceUrl",
      code: "SOURCE_URL_INVALID_TYPE",
      message: SOURCE_URL_INVALID_MESSAGE,
    });
  } else {
    normalizedSourceUrl = rawSourceUrl.trim();

    if (normalizedSourceUrl.length === 0) {
      issues.push({
        field: "sourceUrl",
        code: "SOURCE_URL_REQUIRED",
        message: SOURCE_URL_REQUIRED_MESSAGE,
      });
    } else {
      let parsedUrl: URL | undefined;

      try {
        parsedUrl = new URL(normalizedSourceUrl);
      } catch {
        issues.push({
          field: "sourceUrl",
          code: "SOURCE_URL_MALFORMED",
          message: SOURCE_URL_INVALID_MESSAGE,
        });
      }

      if (parsedUrl) {
        if (parsedUrl.protocol !== "http:" && parsedUrl.protocol !== "https:") {
          issues.push({
            field: "sourceUrl",
            code: "SOURCE_URL_UNSUPPORTED_PROTOCOL",
            message: SOURCE_URL_INVALID_MESSAGE,
          });
        } else if (!isGoogleMapsBusinessUrl(parsedUrl)) {
          issues.push({
            field: "sourceUrl",
            code: "SOURCE_URL_UNSUPPORTED_PLATFORM",
            message: SOURCE_URL_UNSUPPORTED_MESSAGE,
          });
        }
      }
    }
  }

  if (issues.length > 0) {
    return failure(issues);
  }

  return {
    success: true,
    data: {
      name: normalizedName as string,
      sourceUrl: normalizedSourceUrl as string,
      platform: SUPPORTED_REVIEW_PLATFORM,
    },
  };
}
